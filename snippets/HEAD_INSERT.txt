ADD TO EACH LAYOUT: resources/views/layout/admin.blade.php, pos.blade.php, cashier.blade.php, web.blade.php

1) Immediately after <meta charset="utf-8"> (or <meta charset="UTF-8">), add the synchronous bootstrap script. It must be in <head> and must NOT have defer/async, to prevent a light-mode flash before dark mode is applied:

<script src="{{ asset('assets/js/cc-theme-boot.js') }}"></script>

2) Near the end of <head>, AFTER the layout's own inline <style> block and after existing stylesheet links, add:

<link rel="stylesheet" href="{{ asset('assets/css/cc-theme.css') }}">

Do not add the CSS link before the layout's inline styles; the theme overrides must load last.

3) Immediately before </body>, after Bootstrap and the page's existing scripts, add:

<script src="{{ asset('assets/js/cc-theme.js') }}"></script>

Add each of the three lines exactly once per layout.
