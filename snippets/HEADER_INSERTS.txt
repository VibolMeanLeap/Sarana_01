ADD THE THEME SWITCHER PARTIAL ONCE IN EACH LAYOUT HEADER.

Use this include:

@include('partials.theme-switcher')

Suggested safe locations based on the supplied Sarana_01 project layout:

1) ADMIN — resources/views/layout/admin.blade.php
   Find <div class="user-chip"> in the topbar. Add the include as the first child inside .user-chip, before the avatar/profile.

2) POS — resources/views/layout/pos.blade.php
   Find the action container:
   <div class="d-flex align-items-center flex-wrap gap-2 gap-md-3">
   This is the right-hand group containing the staff name, Workspace, Orders and Sign out. Add the include at the beginning of this group.

3) CASHIER — resources/views/layout/cashier.blade.php
   Find the right-hand header group after </nav>:
   <div class="d-flex align-items-center gap-3">
   It contains the cashier name and Sign out form. Add the include before the cashier name.

4) CUSTOMER WEBSITE — resources/views/layout/web.blade.php
   Find the navbar actions group inside #cleanNav:
   <div class="d-flex align-items-center gap-3">
   Add the include before the existing profile dropdown. Do NOT add a separate row above the navbar.

If the language switcher is already present, keep it and place the theme switcher beside it. Do not remove any existing language, notification, cart, profile, or logout controls. Avoid adding the include twice if you already inserted it.
