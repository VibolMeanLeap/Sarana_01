Apply these middleware declarations to the EXISTING POST login routes in routes/web.php.
Do not replace the whole route file and do not add duplicate route declarations.

STAFF LOGIN (Admin + Cashier): replace the existing POST /login/process declaration with:

Route::post('/login/process', [AuthContoller::class, 'processlogin'])
    ->middleware([
        \App\Http\Middleware\ProtectLoginAttempts::class . ':name,staff',
        'throttle:10,1',
    ])
    ->name('process_login');

CUSTOMER LOGIN: replace the existing POST /store/login/process declaration with:

Route::post('/store/login/process', [CostumerController::class, 'login'])
    ->middleware([
        \App\Http\Middleware\ProtectLoginAttempts::class . ':phone,customer',
        'throttle:10,1',
    ])
    ->name('login');

The field names MUST match the forms/controllers:
- Staff: name
- Customer: phone

After editing, verify the route middleware is actually attached:

php artisan route:clear
php artisan route:list --path=login -v

The output for both POST login routes must include ProtectLoginAttempts AND throttle:10,1.
